# Patterns — optional reading

Not copied by `bootstrap.sh`. These are write-ups of specific designs that worked, kept
separate from the kit core because none of them applies to every project. Read one when the
problem it describes is your problem.

Each is reasoning, not code. A pattern you copy without its rationale is a rule your future
self deletes.

| Pattern | Read it when |
|---|---|
| [pure-core-plus-engine](pure-core-plus-engine.md) | Your logic lives inside a game engine, a framework or a UI toolkit, and you cannot test it |
| [economy-integrity](economy-integrity.md) | Your system moves money, points, items or any conserved quantity between accounts |
| [multi-tool-orchestration](multi-tool-orchestration.md) | You are running two or more CLI agents and wondering how to connect them |
| [staged-prototype](staged-prototype.md) | The project is large and unbuilt, and "where do we start" has no obvious answer |
